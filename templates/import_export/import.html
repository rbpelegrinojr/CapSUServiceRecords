Import Official CapSU Service Records Files Recommended for existing HR files

Use this option when you have the individual per-employee Excel files produced by the standard CapSU Service Records form (one file per employee, with the employee's name at the top and appointment rows below the table headers). You can select multiple files at once.

Hold Ctrl (or ⌘ on Mac) to select multiple files at once.
Expected file layout:
  • A row with NAME in column A — surname in col B, given name in col C, middle name in col D.
  • A row with BIRTH in column A — birth date in col B, birth place in col D.
  • A header row containing FROM / TO labels, followed by the appointment rows.
